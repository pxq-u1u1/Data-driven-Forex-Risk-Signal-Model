# RiskFX｜数据驱动的外汇风险信号模型

**面向跨境企业的外汇敞口监测、历史冲击事件分析与对冲决策支持。**

RiskFX 结合专业外汇行情、金融事件文本分析与持仓风险信息，帮助企业理解市场冲击对外汇敞口的潜在影响，形成“**风险监测 → 风险评估 → 风险处理**”的业务流程。

[English](README.md) · [业务需求](docs/BUSINESS_REQUIREMENTS.md) · [技术方案](docs/TECHNICAL_ARCHITECTURE.md) · [金融计算示例](docs/FINANCIAL_CASE.md)

## 项目亮点

- **专业行情接入：**对接同花顺 iFinD 实时及高频／日内行情接口，持续更新外汇市场信息；实际更新频率及数据可用性取决于订阅服务和数据源时间戳。
- **冲击事件回测：**围绕重大历史冲击开展事件分析与回测，关注特定货币对走势以及与整体外汇市场的联动，而不只研究常态市场波动。
- **30+ 主流货币对：**覆盖多币种敞口分析与跨货币对风险信号比较场景。
- **金融事件识别：**结合文本语义特征、事件相关度、情绪与波动影响评分，辅助识别可能受影响的货币对及方向性信号。
- **完整业务设计：**通过需求文档、功能设计及前端页面，将行情监测、持仓评估、压力情景与对冲决策支持连接起来。

## 解决什么金融问题

跨境企业的收入与支出可能使用不同币种。汇率冲击既可能改变收款的本币价值，也可能增加付款成本；极端行情下，不同货币敞口之间的联动也可能发生变化。

RiskFX 围绕四个问题组织分析：哪些敞口值得优先关注、哪些事件可能影响这些敞口、历史与假设冲击下可能出现什么损失，以及对冲如何改变剩余风险和成本。

| 业务环节 | 金融关注点 | 产品设计 |
| --- | --- | --- |
| 风险监测 | 汇率变化与新出现的事件风险 | 行情仪表盘、货币对走势图、经济与政策事件追踪 |
| 风险评估 | 敞口集中度、波动率、输入的 VaR 指标及风险传导 | 持仓分析、风险信号、风险分级与事件解读 |
| 风险处理 | 情景损失与对冲成本之间的权衡 | 多币种敞口分析、历史事件回顾、压力测试与决策摘要 |

## 历史冲击事件与压力测试

项目围绕以下研究窗口开展历史冲击事件分析与回测，观察特定货币对及整体外汇市场的变化与联动：

| 项目研究窗口 | 事件主题 | 金融分析问题 |
| --- | --- | --- |
| 2007—2009 年 | 次贷危机 | 融资压力与风险偏好变化如何影响外汇敞口？ |
| 2008—2013 年 | 欧债危机及其前后压力阶段 | 主权信用担忧及区域金融压力如何在货币之间传导？ |
| 2015 年 | 股市剧烈调整 | 股票市场动荡与汇率变化、风险重估呈现怎样的联系？ |
| 2020 年 | 公共卫生事件 | 突发冲击如何影响外汇波动与敞口敏感性？ |

上述年份是项目使用的分析窗口，不代表各场危机严格的起止时间。通过可追溯的历史冲击，为关税争端、地区冲突等新情景提供分析参照，并辅助讨论风险处置与对冲方案。

**历史回测与压力测试的作用不同：**前者研究已经发生的市场变化，后者在明确的假设下模拟从常规波动到严重尾部冲击的情景。历史类比用于构建情景和理解风险，不意味着未来事件会机械重复，也不代表能够预测未曾发生的“黑天鹅”。

## 金融事件如何转化为风险信号

事件分析结合金融文本表示、事件相关度、情绪评分及波动影响评分，形成供下游模型使用的特征，并输出货币对、方向及置信分数，辅助风险判断。

其中，文本“波动影响评分”表示对新闻影响的估计，与根据价格收益率计算的统计波动率不同；模型置信分数也不等于保证成立的市场事件概率。

## 基于 ReAct 的多智能体协作金融对冲决策系统

根据项目商业计划书第 4.2 节，技术方案通过 **ReAct、LangGraph 与 LangChain** 组织金融分析与工具调用，并纳入多智能体研究、人机协同及 LangSmith 运行监控设计。

| 组成 | 方案中的作用 | 对应金融需求 |
| --- | --- | --- |
| ReAct | 分析任务、调用工具、观察结果，再继续分析 | 根据持仓情况获取所需风险指标，并完善评估 |
| LangGraph | 管理共享状态、条件分支及分析子图 | 协调敞口、市场波动、相关性与事件分析任务 |
| LangChain | 封装模型接口、提示模板、分析工具及结构化输出 | 复用金融分析组件，统一决策支持信息格式 |
| 多智能体研究 | 拆分子主题，并行分析后汇总 | 将不同分析视角整合为风险报告 |
| 人机协同 | 人工调整研究范围并审阅假设与建议 | 由用户掌握最终对冲决策 |
| LangSmith | 在架构中提供调用追踪及异常、性能监控 | 定位分析流程中的问题，检查工具调用过程 |

上述内容描述项目的技术设计。本次公开版本包括前端源码、业务及架构说明，以及独立的离线金融计算示例；后端服务与模型训练代码不包含在本次发布内容中。

使用 Python 3.10 或以上版本运行独立示例：

```bash
python demo/treasury_case.py
python -m unittest discover -s tests -v
```

该示例无需账号、行情订阅或外部服务，用模拟现金流解释敞口、汇率冲击及对冲成本，独立于历史事件回测。前端的实时行情与分析功能需要配套后端服务；本仓库提供界面源码，并非在线行情终端。

## 项目背景

本项目参加第二十届“花旗杯”金融创新应用大赛。项目获国家级三等奖、全国前二十强。

RiskFX 为学术研究及决策支持原型，不执行真实交易，不构成投资建议。市场数据使用须遵守供应商授权；本次发布不包含供应商凭证、授权行情数据集或模型权重。
